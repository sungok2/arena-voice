# ARMY AI EXCELLENCE ACADEMY — 독립 평가 청사진 v2.4.1 (2027 심의용)

> **주의:** 평가의 구성과 합격기준 모두 *기관 승인 전 제안*. 이 문서로 정식 수료점수 또는 군의 직무 적격성을 판정할 수 없다.

## 2. 수행평가 공통 척도 (5점)
정확성·정합성 0~2, 재현성 0~1, 권한·보안 0~1, 실패·한계 보고 0~1의 합산으로 설계한다. 각 점수의 **행동수준 예시와 경계사례**는 실제 평가용 데이터/정답과 함께 구체화하고 2인 평가자 교정 세션에서 일치도를 검증한다. 단순 "느낌상 우수" 방식 금지.

## 3. Capstone 40점 세부 척도
- 문제·업무·사용자·AS-IS·측정 기준선: 최대 8
- 원천·식별자·시간·정합성·데이터 품질·의미 융합: 최대 8
- AI 방법 선택·비AI 대안·권한 필터·보안·운영 아키텍처: 최대 8
- 독립 시험·근거 문장 검증·오류·불확실성·중단 기준: 최대 8
- 비용·계약/라이선스·위험·단계별 로드맵·책임/승인: 최대 8

**실행계획만 제출**한 경우 실제 구현·성능 달성 증거를 가장해서는 안 된다. 구현형과 설계형의 과업 난이도·허용 증거 차이를 동등하게 시험할지, 아니면 별도 경로를 둘지 기관의 시범평가로 결정한다.

## 4. 독립 지필 WR01 문제은행 개발 절차
- 시험 명세서: 학습성과별 평가할 조건·수행행동·중요도·문항 수·배점/시간·인지수준을 설계하고 분야별 교관/평가전문가가 검토한다.
- 문항작성: 오답은 실제 오류메커니즘에서 구성하고, 동일 영역에서 참인 문장을 맥락 없이 오답으로 차용하지 않는다. 문제마다 단일 최적답, 데이터·보안 조건, 계산 가정, 모든 선택지 해설과 원문 조항/판본을 포함한다.
- 시험보안: 504개 공개 학습문항과 30개 진단문항은 형성평가로 고정하고, 공식 시험 원고·정답키는 평가 주관기관의 **별도 인가 시스템**에서 관리. 공개 GitHub 저장 금지.
- 독립 검수: 저자와 다른 **전공전문가 2인**이 서로의 판단을 보지 않고 원문·정답·유일성·오답품질·공정성을 평가한다. 이견은 제3자 조정 후 수정·재검토. 검수이력 보존.
- 시험도구 분석: 파일럿 자료가 확보된 뒤 문항 정답률(p), 점이연상관·오답 선택 분포, 시험 신뢰도 및 목표 PLO와 관계를 분석. 작거나 편향된 표본만으로 문항의 우수성 수치 확정 금지.
- 표준설정: 기관 교육목표와 오류 비용을 근거로 전문가의 점수 기준 설정(예: 수정 Angoff 또는 수행평가 기준설정), 결과 타당성·불확실성 검토, 사전 공지.
- 평가관리: 인가된 시험감독·부정행위·접근성·응시 사유·대체시험·이의신청·성적보관/파기를 문서화.

## 6. 타당성 확보에 필요한 증거
1. **내용타당성:** 직무분석(요구 PLO), 교과-실습-평가 연계행렬과 2인 검수 보고.
2. **반응과정:** 학습자가 의도한 판단 과정으로 답했는지 면담/인지고찰, 시행 조건.
3. **내적구조:** 표본이 충분하고 측정 목적에 맞을 때 문항수준/총점 신뢰도.
4. **다른 변수와 관계:** 독립 수행평가·기존 직무경험·지연된 현업 재측정 간 관계(적합한 모집단).
5. **판정 결과의 영향:** 오판정·보충교육/재교육·공정성·접근성·보안 비용.

평가 통계의 기준(n·상관·신뢰도 등)은 숫자를 임의로 만들어 넣지 않는다. 파일럿의 모집단, 설계, 불확실성과 실수용 목적을 보고 합의한다.

## 7. 운영 시 안전과 정보보호
- 접근통제는 문서/행/객체/캐시/인용을 포함한 데이터 계층에서 강제하고, LLM 지시만으로 권한을 충족했다고 보지 않는다.
- 실제 군 데이터·개인정보를 공개 실습 원고·문항·코드·시험 산출물·외부 AI 서비스로 내보내지 않는다.
- 교육원별 군 보안심사·자료 반입승인·저장장치·기기·앱서명 검증은 독립적으로 필요.
- 학습 앱의 로컬 자가체크, JSON 내보내기, XP, 기초 진단은 위변조 가능성 때문에 **공식 수료 자료로 인정하지 않는다**.

## 9. 평가 시간·인원 수용성 검토 (v2.4.1)
- 8시간 평가블록은 1주·2주 각 1시간과 10·11·12주 각 2시간이다. 6개 수행평가 PE01~06은 전문학습 또는 프로젝트에서 관찰할 수 있지만 중복 시간계상은 금지한다.
- **12주 2시간만으로 WR01과 모든 학습자의 OR01을 완료할 수 있다는 증거는 없다.** 구술 수용능력은 학습자 수 N, 1명당 실제 소요 t분, 동시평가조 수 P, 평가에 사용할 수 있는 실제 유효시간 M분으로 검사한다: N×t ≤ P×M.
- 구술 평가자 2인 배치, 재평가·장애 편의·장치 문제·대체 시험 등을 고려한 여유시간과 교관 수는 학습자 선발 숫자가 나온 후 검증한다.
- PLO별 합격 요건·영역별 하한은 현재 '제안'이고, 실제 합격기준 타당성은 표준설정과 파일럿 자료로 결정한다.
- 2027년 개설 전 적용 법령·군 내부 교육규정의 현행성과 승인권한을 재확인한다. 내부 규정·응시자 정보·독립시험 정답키를 공개 저장소에 기록하지 않는다.
