# CAP01 + OR01 — 데이터융합·AI사업 28시간 통합 수행과제(공개·합성 시범안)

**분류:** 공개·합성 교육 실습 / 공식 인가·채점자 검수 전 / 실제 군 데이터 사용 금지.
**정규교육 편성 후보:** 10주 8시간 + 11주 10시간 + 12주 10시간 = 28계획시간(별도의 평가 8시간 중 최종 구술·지필 시수는 중복 계상하지 않는다).
**증거 참조:** PE01/02/03/04/05/06 공개 합성 사례의 조건과 실패 패턴을 공통 도메인으로 연결한다.

## 1. 가상 과업 정의
가상 기관 'CIVIL-SYN-OPS'(실재 부대 아님)는 교육·시설 정비 기록과 공개 규정 문서의 품질을 높이고 담당자 질의에 근거를 제공하는 업무를 검토 중이다. 기관은 신뢰되지 않은 이종 CSV/API/문서를 보유하며, 동일 ID 문자열의 충돌·중복 정비사건·그룹 누출·민감성 표기의 오류·프롬프트 주입·이용권 제한을 통제해야 한다.

기관은 **AI를 반드시 도입해야 하는 것이 아니다.** 기존 검색·규칙기반 처리와 AI/RAG를 모두 비교해야 한다. 최신 법령·실제 군 업무 규정의 내용을 이 연습에 입력하지 않는다.

교육생에게 주는 질문:
> 가상 기관이 여러 시스템의 정비·문서 데이터를 결합할 때, 어떤 문제를 해결해야 하며 언제 AI와 비AI 대안을 선택하고, 어떤 증거를 확보해야 운영 승인·중단을 결정할 수 있는가?

## 4. Capstone 예비 루브릭(40점, 기관 검수 전)
1. **문제·사용자·현행 기준선(8점):** 문제 정의, 기준선 관측 또는 미확인 표기, 비AI 대안이 다뤄졌는가?
2. **데이터 품질·연계·의미(8점):** 원천 ID, 이벤트 시점·결측·중복·계약과 권한·계보를 재현했는가?
3. **AI 아키텍처·접근통제(8점):** 모델/RAG의 필요성과 데이터·객체 수준 인가, 명령 주입 대응을 설명했는가?
4. **독립 시험·실패모드(8점):** 검증 자료 분리, 지표 분모, 필수 중단 게이트, 재시험·롤백을 증빙했는가?
5. **사업성과·비용·법적 제약·이행(8점):** 단순비용과 전체 TCO 차이, 데이터 계약·책임, 마일스톤·승인/중단을 기술했는가?

각 8점 영역의 단계별 판정 기준은 현업 전문가와 평가자가 실제 제출물 2인 채점으로 확인·공고해야 한다. 합계가 높아도 군 보안·자료 이용권을 무시한 결과는 별도의 승인 게이트에 따라 처리한다. 현재 배점은 공식 수료 기준이 아니다.

## 5. OR01 구술방어(10점, 공개 연습 질문)
평가자는 다음 질문을 **출제 예시**로 활용할 수 있으나 비공개 공식 구술시험으로 재사용하지 않는다.

1. 동일한 E-01 코드가 다른 원천에 존재하면 무엇으로 같은 자산인지 증명하겠는가?
2. 데이터 정제 후 ‘결측이 사라졌다’는 주장과 결측 데이터를 삭제한 기록은 어떻게 구분하는가?
3. 그룹 분할 모델의 시험 정확도가 높은데 현업 장비에 성능이 낮을 수 있는 원인은 무엇인가?
4. 로그인이 성공했지만 권한 없는 문서를 검색했다면 결함의 통제 지점은 어디인가?
5. RAG가 출처를 제시했으나 출처에 없는 숫자를 답했다면 통과인가?
6. AI 제품보다 비AI 대안이 싸고 성능 기준을 만족하면 어떤 경로를 선택하는가?
7. 전체 시험 통과율이 높은데 필수 접근통제 실패 1건이 발생했다면 배포해도 되는가?
8. 성과·비용 가정이 실제 자료로 입증되지 않은 상태에서 어떤 보고 문구와 승인조건을 제시하겠는가?

**구술 평가 예비기준:** 각자의 주장·숫자·근거·한계 방어 5점, 반례·실패모드 대응 5점. 각 응답의 정답 여부뿐 아니라 근거 추적을 기록한다. 학습자 수·구술시간·독립 평가조 수가 결정되지 않으면 12주 평가 2시간 안에 전원 실시 가능하다고 단언할 수 없다.

## 6. 독립 평가와 공정성
- 공개본에 있는 6개 원천 데이터와 계산 기준은 **연습**용이다. 정식 감독시험은 승인된 기관의 별도 비공개 원천·독립 문항·수용조건으로 실시한다.
- 수행평가 제출물은 증거 ID, 입력·출력 해시, 프로그램 버전, 평가자 A/B의 별도 채점·이견 조정 이력과 함께 권한 있는 교육행정 시스템에 보존한다.
- 학습자 정보·실제 보안/운용자료를 공개 GitHub, 공개 앱, 외부 AI 서비스에 넣지 않는다.
- 현장 파일럿 뒤 오답률·교관일치도·실습 난이도·접근성·학습효과를 근거로 교안을 수정한다.
- 기획형(문서만 제출)과 구현형(실제 코드·실증)의 평가 동등성은 검증되지 않았다. 적용 평가기준과 불확실성을 분리 보고한다.

**현재 판정:** Capstone·구술을 위한 교수자료와 평가 예시 작성 완료. 학습자의 실제 수행성과, 공식 수료평가 적합성, 교관/기관 승인: 미검증·미승인.
