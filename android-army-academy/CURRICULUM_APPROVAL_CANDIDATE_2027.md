# ARMY AI EXCELLENCE ACADEMY — 2027 정규 전문교육과정 심의 후보안
**문서상태:** DRAFT FOR GOVERNING-INSTITUTION REVIEW · 정식 승인 전 · 공개·합성 사례만  
**버전:** 2.4.0 / 2026-11-17 · **수업 주관기관·승인권자·교육명령:** 미지정(기관 확인 필요)

## 0. 개관: 교육 목표 → 교수학습 → 평가 → 승인
```text
[교육수요 분석] 국방·육군 데이터/AI 직무 수행 역량
       ↓  독립적으로 검증 가능한 학습성과 8개(PLO01~08)
[공통 18h] → [전문 90h: AT31·DF30·SP29] → [Capstone 28h] → [평가 8h]
       ↓           주 12h × 12주 = 144h
[실습 증거] 데이터 품질/ID·시간 매핑/ML·RAG 평가/사업·TCO/TEV&V
       ↓
[독립 평가] 지필20 + 실기30 + 프로젝트40 + 구술10 = 100점(안)
       ↓
[승인 G0~G6] 교과·교관·실습·문항·통계·보안·기관 심의
       ↓
[공식 수료 여부] 승인된 기관의 별도 결정. 앱 XP/진도 ≠ 수료.
```
**이 문서 자체로는 기관 인가·교관 인증·수료 자격이 발생하지 않는다.** 실제 육군 교육 운영규정의 현행 원문은 승인된 업무망에서 교육주관기관이 확인한다. 내부 자료를 공개 저장소로 반출하지 않는다.

## 1. 개발 목적과 모집 대상
- **목적:** 부대·기관의 데이터와 AI 업무를 문제정의에서 데이터 품질·융합, 모델 평가, 사업계획, 보안, 설명책임까지 연결해 *재현 가능한 증거*로 보고하도록 교육한다.
- **대상(안):** 데이터·AI·정보화 관련 직무를 수행할 장교·부사관·군무원 및 지정될 실무인력. 군 특화 전문교육인지 전 장병 소양교육인지의 분류와 실제 모집 자격은 교육주관기관 확인 후 확정.
- **선수역량:** 디지털 문해력, 기초 수리력, 규정·보안 기초. 비개발자에게 별도의 예비 Python·SQL 연습과 용어집 제공. 선수기술 수준 확인은 배제·진급·인사 평가 목적에 사용하지 않는다.
- **수업 기간:** 12주 × 12시간 = 144시간 *계획시간*. 1시간의 실제 인정 방식(예: 50분 수업/휴식 포함 여부), 집체·온라인 비율, 출석 산정 방식은 기관의 학칙을 적용하여 재산정한다.
- **교육방법:** 설명식 강의 + 합성데이터 실습 + 모의 의사결정 + 독립 팀 검토 + 개인 포트폴리오. 인터넷 연결 없이 반복 실습 가능; 실제 군사자료·개인정보·비인가 내부망 반입 금지.
- **과목 편성:** 앱의 42개 과목·252개 모듈은 *자료 라이브러리*이고, 12주 필수 교과는 시간표에 실제 배정된 28개 과목의 해당 차시이다. 42개 전부 수강을 144시간 수료 요건으로 오인하지 않는다.

## 4. 교수안·학습 자료의 승인 조건
**1차시 교안 필수 필드:** 강의코드/버전, PLO, 선수학습, 세부 성취행동, 시간, 교수 방법, 공개·합성 데이터 출처/라이선스, 실습 입력/정답 기준, 오류사례, 평가기준, 접근성 배려, 보안·안전 통제, 원문 확인 기록, 교관/검수자 서명.
- 기존 252개 강의 원고는 별도 전문가 확인 전 초안이다. 각 원고의 사실 주장에 대해 **원문 해당 절·페이지·버전·시행일**을 추적할 수 있도록 보완한다.
- 504개 모듈 객관식, 30개 진단문항은 독립 검증·응답분포 분석이 없으므로 **공식 수료시험 배점에 반영하지 않는다**.
- 기존 15개 가상 자동채점 실습은 학습 연습으로만 사용한다. 공식 수행평가는 별도의 과제지·교관 채점표·재현증거·이의신청 기록이 있어야 한다.
- 원자료는 공개 허가와 실습 재배포 허가를 구분하고, 사용 권리가 불분명하면 대체 합성 자료를 사용한다.

## 5. 평가설계 — 기관 승인 전 제안
**100점 평가 배점:**
1. WR01 독립 서면평가 20점 — 미승인 504·30문항과 분리된 신규 검증문항은행 필요.
2. PE01~PE06 수행평가 6개 × 5점 = 30점 — 데이터 정제·조인/융합·ML 평가·RAG 인가·사업경제성·TEV&V.
3. CAP01 종합 포트폴리오 40점 — 문제·기준선 8, 데이터·융합 8, 아키텍처·권한 8, 독립시험 8, 비용·법률·이행 8.
4. OR01 구술 방어 10점 — 증거와 한계 5, 반례와 실패 대응 5.

**이수 기준(권고·미승인):** 계획 출석률 90% 이상(144시간의 90%를 올림한 130시간), 총점 70점 이상, WR≥12/20·수행≥18/30·프로젝트≥28/40·구술≥6/10을 각각 충족하며 중대 보안·권리·허위보고 위반 0건. **절대적으로 정해진 군 이수 규칙이 아니며** 교육기관의 표준설정, 파일럿 결과, 학칙에 따라 수정·승인해야 한다.

실습과 종합과제는 독립 평가자 2인의 별도 채점을 원칙으로 권고한다. 평가자 불일치 허용 폭, 제3자 조정, 시험 대체·보충평가, 시험 접속성·장애 대응·이의신청은 시행 전 공지하고 기록해야 한다. 평가 기준은 시험 실시 후 임의 변경 불가.

**승인권한의 특정은 현재 자료만으로 단정 불가.** 육군 AI 교육 관련 규정의 승인된 최신 원문과 해당 기관의 교육 운영절차를 대조해 결정한다. 공개 AI 규정과 국방데이터 훈령만으로 인가 절차를 임의 확정하지 않는다.

## 7. 교관·운영 인력 및 통제(초안)
- 교육과정 책임자: 대상·학습목표·교과 변경·교육품질 승인 건의.
- 교육운영 담당: 선발·시간인정·출석·기록·시험 감독·시설.
- AI 전문교관/데이터 전문교관/사업·정책 전문교관: 차시교안·실습·답안 타당성 검증과 교수.
- 평가품질 담당(교과 개발자와 분리): 평가 청사진, 독립 채점, 정답 키 통제, 파일럿 통계와 이의신청.
- 정보보호/보안 담당: 데이터·기기·망·산출물 분류와 반출입, 취약성 검토.
- 승인권자: 기관 규정에 따라 정식 시행·수료 인정 여부를 최종 결정.

교관의 임명요건은 실제 규정에 맞춰 확정한다. **단순 개발 참여, 앱 레벨, 문제은행 기여를 교관 자격으로 인정하지 않는다.**

## 8. 파일럿·개선계획(계획이지 실적 아님)
- Phase 0: 문헌·현업 직무분석, 교관/임무전문가의 PLO 적합성 심사.
- Phase 1: 강의별 원문·학습목표·문항 2인 독립 검토와 수정 추적; 모호·복수정답 문항 제거.
- Phase 2: 비식별·합성 환경의 파일럿. 사전-사후 동형 평가, 6 수행평가·Capstone 채점 편차/오류 분석, 학습자 접근성·실기기 확인.
- Phase 3: 평가표준 설정(최저합격선·최소중요영역), 공정성·안전 검토, 교관 재교육, 교육 승인 건의.
- Phase 4: 승인된 장소·기기·반입 매체에서 운영하고, 동기수료 실적·3~6개월 현업 전이를 *조사 설계 후* 평가.

교육효과의 표본 수와 목표 통계량은 파일럿·기관의 사용 목적이 확정되지 않아 임의로 채우지 않는다. 표본 설계 없이는 기존 앱 정답률이나 XP로 전문 역량을 추정하지 않는다.
