# ARMY AI Academy — 교육품질 심사규정(프로젝트 제안, 공식 규정 아님)
상태: **교육용 원고 / 자동 구조검증 통과 가능 / 독립 전문가 심의 및 기관 승인 미완료**.

### 절대 승인 불가 결함(P0)
사실 오류나 잘못된 정답, 실제 군사자료·개인정보 유입, 저작권·라이선스 위반, 작동하지 않는 모듈, 공식 이수·인증 오인 유발.

### 모듈당 품질평가표 (100점, 제안)
|검증영역|배점|증빙|
|---|---:|---|
|사실성·최신성|25|주장별 1차 공식자료·조항·발행일·원문 대조|
|학습목표와 학습활동 정렬|15|수준·선수요건·기억/적용/평가 목표 대조|
|실습의 재현성|20|입력·절차·정답/산출물·오류사례·환경|
|평가문항 타당성|20|정답·해설·동일한 수준의 오답지·복수정답 위험|
|보안·권리·윤리|10|공개·합성 자료, 이용권한, 비인가 내부데이터 배제|
|접근성·작동성|10|갤럭시·스크린리더·폰트·복원·오류 흐름|

**제안 승인조건:** 모듈별 90점 이상·핵심 사실성 23/25 이상·평가 18/20 이상·보안 10/10, P0=0, 교관 검토 서명과 실기기 시험 완료.
이 기준은 소속기관의 공식 심사규정이 아니므로 채택·수정 여부를 승인권자가 정해야 한다.

### 검수자
도메인 전문가(42과목·252모듈 전수 내용 심사), 교육설계 전문가(목표-실습-평가 정렬), 재현성 실습검증자, 보안·법무 담당자, 최종 교육 승인권자.
검토자 성명·서명·검증 날짜·문서번호는 실제 수행 및 확인 전 기재하지 않는다.

### 단계
DRAFT → AUTOMATED_STRUCTURE_QA → FACT_CHECKED → INSTRUCTIONAL_REVIEWED → LAB_REPRODUCED → SECURITY_LEGAL_REVIEWED → PILOT_EVALUATED → AUTHORIZED.
현재 허용 단계는 AUTOMATED_STRUCTURE_QA 후보이며 **AUTHORlZED 상태를 주장할 수 없다**.

### 학습효과
형성평가와 수행평가를 분리하고 사전/사후 학습, 4주 지연 시험, 현업 전이(보안 승인된 익명 자료 사용), 사용자 만족·실습 성취·업무지표 개선 증거를 독립 확보.
수행평가 15개는 합성 자동채점 **연습**, 전문성 인증이 아니다.
