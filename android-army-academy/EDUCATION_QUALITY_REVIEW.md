# ARMY AI EXCELLENCE ACADEMY v2.3.2 — 교육·소프트웨어 품질 심의 기록

> **교육 품질 승인: NO-GO (전문가 검토 전 초안).** 이 문서는 검토 절차이며 공식 육군 교육과정 또는 이수 인증이 아닙니다.

## 1. 확인된 범위와 소프트웨어 개선
- 42개 과목 / 252개 모듈 / 객관식 504개 / 진단 30개 / 합성 가상 실습 15개.
- 12주 144시간 학습 계획, 전문학습 시간 비율 AT/DF/SP=34/33/33 권고안을 유지.
- v2.3.1에서는 객관식 선택지·돌아가기·채점 실패 시 입력 중이던 실습 답변과 미제출 실습 값이 재렌더링으로 유실될 수 있음.
- v2.3.2에서는 메모리 전용 module_draft.js가 이 입력값을 보존하도록 수정. **미저장 초안은 앱 종료·강제 종료 시 복구되지 않음.** 승인된 실습 이력과 별도 취급.
- 새 회귀검사: qa/module_draft_test.js. 실제 갤럭시·Android 에뮬레이터의 입력/회전/중단·복원은 별도 실기기 검증 필요.

## 2. 문항은행 — 534문항 자동 검토대장
- 객관식 504개 중 **480개**는 다른 모듈의 '정답으로 지정된' 문장을 오답으로 재사용한 `NEAR_DOMAIN_CHOICE` 초안. 실제 복수정답 가능성이 있으므로 가장 높은 검토 우선순위.
- **24개**는 별도 작성한 계산·상황판단형 `APPLIED_SCENARIO` 초안. 계산 가정, 실제 정답 및 설명, 출처 개별 검증 필요.
- **30개** 기초 진단 역시 다른 정답 문장을 선택지로 재활용하였으며, 난이도·변별도는 검증되지 않음.
- `node qa/question_bank_review_export.js --out review-artifacts`는 534개 고유 ID, 정답, 해설, 선택지, 출처, 위험요인, 2인 전문가 검토란이 있는 CSV와 JSON 요약을 작성. 구조검사 성공은 문항의 참·거짓을 증명하지 않음.

## 4. 전문가 검토 규칙 (권고안)
1. 분야별 전문가 **2인이 서로의 답안을 보지 않고** 각 문항의 정답 유일성, 선택지의 조건부 참·거짓, 해설 및 참조 원문의 직접적 관련성을 판정한다.
2. 두 판정이 충돌하거나 정답 후보가 복수인 경우 사용을 보류하고, 제3검토자 조정 후 문항을 수정·재검토한다.
3. 모든 문항에 학습목표 ID, 출처의 구체적 절/버전, 생성·수정 이력 및 최종 검수자 기록을 남긴다.
4. 군 현업 역량은 실제 군 자료가 아닌 **비식별·합성** 정책기획, DB 조인, 데이터 품질, RAG 접근통제, 사업 경제성/TEV&V 사례로 평가한다.
5. 통과 문항만 파일럿에 투입하며, 파일럿의 응답자료는 최소수집·명확한 동의를 전제로 분석한다. 적합한 표본설계 없이 정답률·변별도·신뢰도 수치를 추정하지 않는다.
6. 문항 승인과 실습 결과 자체 점검은 공식 교육 승인 및 군 임무 수행 권한과 별개다.
