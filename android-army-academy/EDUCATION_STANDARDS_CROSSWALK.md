# 데이터·AI 전문교육 국제·국내 공개자료 대비표 (v2.5.0)

**용도:** 국방·민간 공개자료의 개념·목표를 12주 교육과정 PLO/실습에 대조하기 위한 검토 초안. 타국 기관 자료를 한국군의 강행 규정이나 육군 교육인가 근거로 오인하지 않는다.

## 1. 해외 국방 데이터 전략과 교과목 간 연결
미 국방부 공개 *DoD Data Strategy*는 데이터를 **Visible, Accessible, Understandable, Linked, Trustworthy, Interoperable, Secure (VAULTIS)** 하게 관리한다는 목표를 설명한다. 출처: [DoD 공식 설명, 2021-03-03](https://www.defense.gov/News/News-Stories/Article/Article/2523066/official-explains-dod-data-strategy/source/official-explains-dod-data-strategy/), [해군 CIO 공개 보도](https://www.doncio.navy.mil/CHIPS/ArticleDetails.aspx?ID=13958).

| VAULTIS 목적 | 과정 학습성과 | 실제 교육 검증 과제 | 평가상 주의 |
|---|---|---|---|
| Visible 데이터 발견성 | PLO03·04 | 메타데이터 사전, 원천·버전 기록 | 발견만으로 이용허가 성립 안 함 |
| Accessible 권한 있는 사용 | PLO02·06 | PE04 객체별 인가 부정시험 | '검색 가능'과 '권한 있음' 구분 |
| Understandable 의미·맥락 | PLO03·04 | PE01 결측/단위·PE02 ID 스코프 | 같은 숫자가 같은 실체임을 증명하지 않음 |
| Linked 출처 간 관계 | PLO04 | PE02 원천별 키/고아 분리 | 문자열 일치만으로 JOIN 불가 |
| Trustworthy 신뢰성 | PLO03·05·08 | PE01 품질·PE03 시험 독립성 | 결함률·정확도의 분모·대표성 필요 |
| Interoperable 표현·통합 | PLO04 | PE02 schema/ID/time, API/Contract | 중앙 복제가 자동 해답은 아님 |
| Secure 무단사용 방지 | PLO02·06·08 | PE04 인가·PE06 필수 보안 중단 | AI 응답 거절만으로 서버 접근통제를 대체 불가 |

이 대응은 **본 과정 개발자의 교육설계 분석**이다. DoD 또는 ROK 육군이 이 과정을 공식 인정했다는 주장은 아니다.

## 2. NIST AI RMF 1.0과 수행 증거의 교차검사
근거: [NIST AI RMF Core 공식 공개판](https://airc.nist.gov/airmf-resources/airmf/5-sec-core/), [NIST MANAGE Playbook](https://airc.nist.gov/airmf-resources/playbook/manage/).

| AI RMF 영역 | 대응 과업 | 시험으로 확인할 위험 |
|---|---|---|
| GOVERN | 권한·역할·책임 PLO02·07·08 | 승인권자 불명·감사/정책 부재 |
| MAP | 업무문제·영향·AI/비AI 대안 PLO01·07 | 필요성 과장, 데이터 권리 미확인 |
| MEASURE | 데이터 품질·ML·RAG 독립평가 PLO03·05·06 | 누출, 문장 근거 부족, 시험 분모 오류 |
| MANAGE | 중단/재시험·사업비용·운영 PLO06·07·08 | 필수 보안 게이트 위반, 비AI 대안 무시 |

NIST RMF의 원칙을 교육용 평가기준으로 참고하는 것이며 예제의 수치/배점/컷오프는 NIST의 공식 지정 값이 아니다.

## 3. 평가·교육타당성 근거
[NCME/AERA/APA 공동 Testing Standards](https://ncme.org/resources/books/testing-standards/)는 교육 평가의 목적·점수 사용·타당성·공정성에 관한 전문적 기준을 제공한다. 
- 504개 공개 자가확인 문제, 30개 비규준 진단, 6개 공개 수행 연습은 실제 공식 수료능력 지표로 사용 불가.
- 공식 수료시험은 기관이 공고한 성취기준과 근거를 바탕으로 **별도의 검증된 문항·감독·독립 평가자·성적원장**을 갖춰야 한다.
- PLO01~08의 수행 내용과 전문가 직무분석 결과가 일치하는지는 아직 검증 자료가 없다. 파일럿의 실제 응답자료 없이 문항 변별도·신뢰도·학습효과 통계를 기입하지 않는다.

## 4. 한국 공개 훈령의 현행성 점검
- [국방데이터 관리 훈령](https://www.law.go.kr/admRulLsInfoP.do?admRulSeq=2100000273654)은 데이터 생애주기·품질관리의 정책 배경을 제공하며, 이 과정의 PE01·PE02 데이터 거버넌스 개념과 연관된다. 교육시간·교관·수료의 공식 인가 증거를 대신하지 않는다.
- [국방데이터·인공지능업무 훈령](https://www.law.go.kr/admRulLsInfoP.do?admRulSeq=2100000276642) 현재 공개 판본 제13조에는 2027-06-01 존속기한이 명시돼 있으므로 교육 시행 당시 재발령·개정 여부를 다시 확인한다.
- 육군 내부 교육규정과 학칙·보안 검토 자료는 허가된 내부 환경에서만 점검하며 공개 GitHub에는 원문·제한된 발췌를 저장하지 않는다.

## 5. 기관 심의 시 확인해야 할 증거
| 공개 근거에서 교육으로 이어지는 질문 | 현재 제출 가능한 것 | 실제로 아직 없는 것 |
|---|---|---|
| 데이터가 현업에서 '신뢰 가능'한가? | PE01/02 완전 합성 오류 시험 | 실제 직무 데이터 품질 평가 및 운영 성능 |
| AI가 대안보다 낫고 적법한가? | PE05 가상 비교·가격 가정 | 기관 실제 업무 기준선·권리·비용 검증 |
| 모델을 독립적으로 검증했는가? | PE03 합성 혼동행렬 계산 | 실제 독립 시험·표본/분포/불확실성 |
| 위험을 제어하고 중단하는가? | PE04/06 합성 인가/시험 | 실제 기기/망 보안 적합성·교관 승인 |
| 수료자의 역량이 검증됐는가? | PLO·28시간 Capstone과 공개 모의 루브릭 | 파일럿 학생 결과·이중 채점·공식 성적원장 |
| 육군 기관이 인가했는가? | 심의 후보안·G0 구조 자동검사 | 승인권자 결재·학칙·정식 교육명령 |

**최종 판단:** 원칙과 공개 근거의 추적 가능성은 개선됨. 실제 교육내용 타당성·현장 적용·공적 자격은 **미검증, 미승인(NO-GO)**.
