# ARMY AI EXCELLENCE ACADEMY — 수행중심 6개 실습 교관 패키지 v2.5.0

**문서 신분:** 공개·합성 모의실습 / 교관·평가 전문가 승인 전 / 정규 감독시험 사용 금지.  
**교육과정:** 12주 144계획시간(공통 18 + 전문 90 + 프로젝트 28 + 평가 8), 공개 라이브러리는 42개 과목·252개 모듈.  
**이번 산출물의 범위:** 교육목표 PLO01~08에 연결되는 **PE01~PE06 모의 수행 실습**. 별도 WR01 독립 시험은행 및 공식 성적처리 기능은 만들지 않는다.

## 1. 학습자가 직접 해야 하는 공통 절차
교관은 먼저 사례의 **권한·가정·요구조건**을 제공한다. 학습자는 다음 증거를 각자 제출한다.
1) 문제와 판단 기준선, 원천 데이터(버전·분모·단위·출처); 2) 처리 절차(SQL·Python·표·계산식 등);
3) 정상·실패·경계 사례; 4) 결과 및 불확실성; 5) 누가 어떤 조건에서 결정을 승인해야 하는지.

점수만 맞췄다고 실습을 끝냈다고 표시하지 않는다. 5점 공통 루브릭은
정확성·정합성 2점, 반복 재현 1점, 권한·안전 1점, 한계·보고 1점이며 **배점과 이수 반영은 모두 승인 전 제안**이다.
평가자 간 일치 여부는 실제 수강자 제출물을 이용한 독립 채점 실증이 있어야 한다.

## 2. 실습별 구체 강의 및 근거

### PE01 | 정제·ETL·품질 규칙 (6주 / PLO03)
- **시나리오:** 8개 합성 정비 이벤트의 중복·누락 자산 ID·잘못된 상태·무효 날짜를 수신.
- **조건:** 이벤트 ID로 중복 제거 후 고유 레코드의 자산 ID, 상태, ISO 시간대를 검사. 잘못된 원천은 조용히 보정하지 말고 격리.
- **교관용 기대 결과:** 원본 8 → 중복 1 → 고유 7 → 격리 3 → 유효 4. 원본 기준 자산 ID 완전성, 상태 유효성, 날짜 유효성은 각각 7/8=87.5%.
- **실습 제출물:** 결함 규칙표, 정상/중복/격리 3개 결과 테이블, 오류 기록, 재현 코드, 분모와 품질한계.
- **오류 반례:** 유효 4건만 남긴 후 원래 8건 중 4건이 있었다는 사실을 지우거나, '고유 7'을 '원본 8'과 혼동.
- **참고 근거:** [ISO/IEC 25012 데이터 품질 모델](https://www.iso.org/standard/35736.html). 이것은 품질 차원의 일반 모델이며 **개별 합성 숫자들의 출처가 아니다**.

### PE02 | 이종 ID·조인·이벤트 융합 (8주 / PLO02·03·04)
- **시나리오:** 원천 ALPHA/BRAVO가 각자 E-01과 M-001 코드를 사용하는 4개 합성 장비·7개 이벤트.
- **조건:** 자산은 (system, source_asset_id), 이벤트 중복은 (system, event_id)로 다르게 구분; UTC 통합.
- **교관용 기대 결과:** 원천 7, 중복 1, 고유 이벤트 6, 연계 불가 1, 연계 이벤트 5. 정규 장비 4대. +09:00 12:00 → UTC 03:00.
- **실습 제출물:** 정규 ID 매핑 사전, 중복/고아 격리 내역, UTC 변환 코드, 단위·시점 기준, 연계 범위 승인계획.
- **오류 반례:** E-01 문자열만으로 JOIN해서 ALPHA와 BRAVO 자산을 동일하다고 추정하거나 이벤트 M-001을 원천 간 중복 처리.
- **참고 근거:** [PostgreSQL JOIN 조건](https://www.postgresql.org/docs/current/queries-table-expressions.html). 상세 예시는 [PE02 교관 교안](training_cases/PE02_INSTRUCTOR_LESSON_PLAN.md).

### PE03 | 독립 그룹 분리·ML 오류분해 (9주 / PLO05)
- **시나리오:** 가상 장비 A~F 각각 2건, 총 12개의 고정 정답·예측. A~C 학습, D~F 시험.
- **조건:** 한 장비의 반복관측을 학습·시험 모두에 넣지 않는다. 이 예시는 모델 학습이 아닌 **고정 예측값의 평가**.
- **교관용 기대 결과:** 시험 6건, TP=2, TN=2, FP=1, FN=1, Accuracy=4/6≈66.7%, Precision=2/3≈66.7%, Recall=2/3≈66.7%.
- **실습 제출물:** train/test 자산 ID 교집합 검사, 혼동행렬과 지표 계산, 작은 시험표본의 한계, 재현 코드.
- **오류 반례:** 같은 장비의 여러 행을 임의 분할하여 새로운 장비에 대한 일반화를 주장; 학습 6건을 시험 정확도 분모에 추가.
- **참고 근거:** [scikit-learn 교차검증과 GroupKFold](https://scikit-learn.org/stable/modules/cross_validation.html), [모델 평가](https://scikit-learn.org/stable/modules/model_evaluation.html).

### PE04 | RAG 문서별 인가·근거지원·프롬프트 주입 (9주 / PLO02·06)
- **시나리오:** 가상 PUBLIC 문서·RESTRICTED_SYNTHETIC 문서 2개, 읽기 역할 2종, 5개 질의.
- **조건:** 1단계 객체 읽기 권한, 2단계 확인 가능한 원문 주장, 3단계 검색자료 안의 명령어를 무시. 외부 호출은 실행하지 않는다.
- **교관용 기대 결과:** 인가·근거가 모두 있는 응답 3, 접근거부 1, 자료 없는 주장 유보 1, 외부 실행 0.
- **실습 제출물:** 각 질의별 결정과 근거 문서 ID, 거부·유보 사유, 명령 주입 우회 방지 설계.
- **오류 반례:** '로그인 사용자'라는 이유로 접근권한을 생략하거나, 공개된 문서 내용을 시스템 명령으로 실행.
- **참고 근거:** [NIST AI RMF](https://airc.nist.gov/airmf-resources/airmf/5-sec-core/). 가상 제한등급은 실제 군 보안등급과 무관한 교육용 문자열이다.

### PE05 | 비AI 대안·사업비용·이용권 (10주 / PLO01·07)
- **시나리오:** 가상 사업안 AI-ONPREM, AI-SAAS, RULES(비AI) 비교. 금액 단위는 **백만원**, 5년, 할인율 0 가정.
- **조건:** 전 옵션 처리시간 120초 이하. 데이터·학습 목적 이용권이 없으면 저가라도 탈락.
- **교관용 단순 비용 결과:** AI-ONPREM 600+5×100=1,100백만원; AI-SAAS 100+5×190=1,050백만원이나 학습권 불허; RULES 250+5×110=800백만원, 조건 충족. 이 가정에서는 RULES 선택.
- **실습 제출물:** 비용 식·단위·민감도, 학습권 결격 여부, 비AI 대안 포함 의사결정표, 미포함 비용.
- **오류 반례:** '1,050이 1,100보다 작다'는 이유로 학습 금지 데이터를 활용하거나, 직원·전환·보안비용을 빼놓고 실제 TCO라고 단언.
- **참고 근거:** [NIST AI RMF Manage 2.1](https://airc.nist.gov/airmf-resources/playbook/manage/)은 위험 완화 시 비AI 대안도 고려하도록 안내한다.

### PE06 | TEV&V·필수 중단 조건 (12주 / PLO08)
- **시나리오:** 합성 시험 20건 중 18건 통과, 2건 실패. 그중 1건은 문서별 접근통제 필수 게이트 위반.
- **조건:** 전체 통과율 최소 85%, **필수 접근통제 실패 0건**을 사전 수용기준으로 정함.
- **교관용 기대 결과:** 전체 통과율 90%로 수치 게이트는 충족. 필수 인가 실패 1건이므로 **NO-GO**, 원인 조사·통제 수정·부분/전체 회귀시험 후 재심사.
- **실습 제출물:** RTM, 고장 심각도, 독립 재시험 증거, 운영 중단·복구·인간 승인 경로.
- **오류 반례:** 통과율 90%에만 집중해 필수 보안 실패를 무시하고 배포 승인.
- **참고 근거:** [NIST AI RMF](https://airc.nist.gov/airmf-resources/airmf/5-sec-core/). 본 사례의 85%와 0건은 NIST가 규정한 기준이 아닌 **교육용 가정**이다.

## 3. 자동 재현과 교관 검증은 별개
실행 명령:
- `node qa/synthetic_practicum_test.js`: PE02 원본 사건·조인·UTC 재검산
- `node qa/performance_case_suite_test.js`: PE01/03/04/05/06 원본에서 기대값 재검산
- `node qa/offline_practice_bundle_test.js`: 앱에 실습 입력이 정확하게 들어갔는지와 답안 제거 상태 검사

**위 검사는 구조와 계산이 맞는지 확인할 뿐**, 학습자의 실제 사고과정, 수업시간 적정성, 교관 채점 편차, 편향·접근성, 실업무 전이, 독립 시험 타당성까지 보증하지 않는다. 그 항목은 파일럿과 전문 검수가 필요하다.

## 4. 공개 앱에서 진행하는 절차
12주 시간표의 **합성 데이터 수행 연습**에서 여섯 사례를 펼치면 목표·판단조건·입력자료가 보인다. '공개 실습자료 저장'은 학생용 입력과 제출요구를 JSON으로 저장하며 정답 키는 내보내지 않는다. 그러나 교관 참고 답은 공개 GitHub에 있으므로 비밀 시험과제로 취급하지 않는다. **학습자가 입력하거나 제출한 공식 성적을 앱에서 발급하지 않는다.**

## 5. 평가자 합의·재평가 프로토콜
| 관찰 차원 | 0점 | 중간 | 최대 |
|---|---|---|---|
| 정확성/정합성(2) | 기본 단위/분모/조건 오류가 핵심 결론을 바꿈 | 일부 맞으나 핵심 실패 또는 검증 누락 | 기준선·분모·예외·정확한 결과를 제시 |
| 재현성(1) | 실행 가능 근거 없음 | 해당 없음 | 동일 입력에서 검증 가능한 절차·결과 |
| 인가/안전(1) | 권한·게이트 위반을 무시 | 해당 없음 | 허용된 데이터·통제·인간 승인 명시 |
| 한계보고(1) | 추측을 사실로 단정 | 해당 없음 | 실패/불확실성/적용 범위를 구분 |

각 교관은 **다른 평가자의 점수를 보기 전에** 스코어와 증거 ID를 기록한다. 결과 차이는 원인을 기록하고 승인된 기준에 따라 제3자 검토를 요청한다. 피드백과 재평가 경로를 사전 공지한다. 표준화된 실제 난이도 및 기준점은 미검증 상태.

## 6. 공식 교육 채택 전 추가 증거
- 각 실습을 현업 직무분석의 과업·성과 지표에 매핑하고 분야 전문가 2인 검증.
- 데이터·답안·소스 링크의 주장별 출처 검증, 강의 교안과 시간의 현장 파일럿.
- 독립 시험은행과 실제 평가원장 분리; 정식 출제자료를 공개 저장소에 탑재 금지.
- 승인된 단말·망·자료 반입·보안, 교관·평가자·학칙·기관 결재.
- 현재 6개 실습은 **공개 모의훈련 패키지**이지 공식 채점 도구가 아니다.
