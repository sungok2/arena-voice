# 개인정보 처리 및 이용 안내 (오프라인 앱)
최종 갱신: 2026-11-16 · 앱 버전: 2.0.0

이 문서는 소스코드 구현 현황에 따른 배포 준비용 안내이며, 국방부·육군의 공식 개인정보 처리방침 또는 공식 서비스 승인이 아닙니다.

- **처리하는 정보**: 사용자가 앱에 입력한 학습 진도, 진단 결과, 관심 과목, 실습 메모, 설정 및 XP 내역.
- **보관 장소**: Android WebView의 기기 내부 저장소(localStorage). 별도 서버 전송 기능을 구현하지 않았고 앱에서 Android INTERNET 권한을 요청하지 않습니다.
- **수출·복원**: 이용자가 선택한 JSON 파일로 직접 내보내기/가져오기를 수행할 수 있습니다. 내보낸 JSON은 앱 외부 저장 공간에 존재하므로 사용자 책임하에 보호·삭제해야 합니다.
- **기본 설정**: 효과음·진동은 사용자 선택이며 마이크 권한, 위치 권한, 연락처 권한을 요청하지 않습니다.
- **기록 삭제**: 앱 데이터 삭제 또는 앱 제거로 기기 내부 기록이 삭제될 수 있습니다. 외부로 내보낸 백업 파일은 별도 삭제가 필요합니다.
- **제3자 분석/광고**: 구현된 앱에는 광고·분석 SDK 또는 외부 AI API가 포함되어 있지 않습니다. OS 또는 배포 플랫폼이 자체적으로 수집하는 진단·설치 정보는 별도 정책을 따릅니다.
- **안전성**: 실제 군사기밀, 비공개 작전정보, 민감정보, 실제 개인정보를 실습 메모에 입력하지 마세요.
- **문의처**: 실제 서비스 운영·배포 주체와 연락처가 정해지면 배포 전 기재해야 합니다 (현재 미지정).
