# PE02 데이터 융합 실습 — 교관용 시범 교안 (미승인)

**대상:** 기초 SQL·Python 조인 교육 이수자. **범위:** 순수 합성 자산·정비 이벤트. **관련 성과:** PLO02, PLO03, PLO04. **원천:** PE02_data_fusion_identity_synthetic.json

## 목표·과업조건
입력된 자산대장 4행, 이벤트 7행을 원천 ID 스코프로 올바르게 연결하고 (1) 중복·고아 이벤트, (2) 정규 ID별 집계, (3) UTC 정규화, (4) 데이터 출처·권한·한계의 증거를 제출한다. 같은 E-01 코드도 원천 시스템에 따라 실제 서로 다른 가상 자산이다. M-001 이벤트 ID 역시 원천별로 독립적이다.

## 시간배정(60분 예시, 기관 미승인)
| 단계 | 시간 | 학습자가 수행할 관찰 가능 행동 | 증거 |
|---|---:|---|---|
| 출처·권한·ID | 10분 | 원천 식별자와 사건 식별자의 스코프 설명 | 조건 메모 |
| 조인 설계 | 10분 | 복합키 (system, source_asset_id)를 정의 | ERD와 조인 조건 |
| 정제·품질 | 15분 | (system,event_id) 중복 제거, 고아 분리 | 처리·오류 기록 |
| 시간 표준화 | 10분 | UTC 변환과 출력 재현 | 실행 코드·검증표 |
| 검증·위험 | 10분 | 유효 건수·고아·원천의 한계 보고 | 결과·오류분석 |
| 피드백 | 5분 | 교정·성찰과 재학습 소요 기록 | 피드백 기록 |

**60분은 시연용 시간**이며 군 교육운영 규정상 1교시 기준이나 학습 효과의 검증 값은 아니다.

## 검증 가능한 정답(이 공개 예제는 정식 시험 사용 불가)
- 원천 이벤트 7건, (system,event_id) 중복 1건, 중복 제거 후 고유 이벤트 6건.
- 정규 자산과 매핑 불가 BRAVO:E-99 1건, 연계 가능한 유효 이벤트 5건.
- 정규 자산은 4개. SYN-1001=2, SYN-1002=1, SYN-2001=1, SYN-2003=1.
- ALPHA:M-003의 2026-10-05T12:00:00+09:00을 UTC로 변환하면 2026-10-05T03:00:00Z.
- ALPHA:M-001과 BRAVO:M-001은 시스템이 다르므로 중복이 아니다.

**오개념 반례:** 자산ID 문자열만으로 조인하면 같은 E-01을 가진 두 원천 사이에서 잘못된 다대다 연계가 발생한다. 이벤트 ID만으로 중복 제거하면 서로 다른 원천의 M-001을 합쳐버린다. orphan을 강제로 정상 자산에 매핑하거나 제외 사실을 숨기는 것도 잘못이다.

자동 재현 명령: node android-army-academy/qa/synthetic_practicum_test.js. 단위시험은 원천 입력으로 정답을 독립 계산하고 기대값과 비교한다. 이 기술 시험으로 교관 검증 및 현업 타당성을 대체하지 않는다.

## 수행평가 5점 예비 루브릭
- 정확성·정합성 2점: 복합키와 집계의 올바름. 0/1/2점 경계 사례는 교관 파일럿에서 확정.
- 재현성·시험근거 1점: 입력·코드 또는 SQL·결과·실행조건을 재현할 수 있음.
- 권한·보안 1점: 가상 자료와 원천별 이용권을 구분하고 미허가 자료·연계를 배제.
- 한계 보고 1점: 고아·중복·권한 미확인/의미적 불확실성과 후속 조치가 기록됨.

평가자 A·B의 개별 채점, 시험자·버전·기록 해시·불일치 조정은 실제 인가된 평가 시스템에만 남긴다. 공개 저장소에는 수료자 이름·점수·실제 군사 업무 자료를 남기지 않는다.

**공식 전환 조건:** 기관이 독립 비공개 시험과제를 신규 제작하고, 정답 유일성·통제권한·난이도·공정성과 교관 채점 일치도를 검증하며, 합격·이의신청 규정을 사전 승인한다. 공개된 정답을 가진 이 예제를 그대로 수료시험에 사용하는 것은 금지.
